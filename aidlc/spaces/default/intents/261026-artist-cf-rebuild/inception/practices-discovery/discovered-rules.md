# Discovered Rules

> Hard rules the owner confirmed in the practices-discovery interview (Q7: A, B,
> C, D). Candidate D is split into one `NEVER` rule and one `ALWAYS` rule. Each
> origin is recorded in `evidence.md`.

## Mandated

- ALWAYS run the pre-merge check (lint, format check, type check and tests with the 80% coverage floor) and have it pass before a Bolt is merged into `main`.

## Forbidden

- NEVER modify, move or write into the ListenBrainz and MusicBrainz dumps in `../listenbrainz`; read them in place only.
- NEVER show or return data about individual ListenBrainz listeners in the app; only artist-level results leave the pipeline.
- NEVER add a paid service or cloud compute dependency.
- NEVER commit raw dumps, intermediate data or built model files to git; they are regenerated by the pipeline.
